# Canaan CanMV K230 V3.0：外接 PDM 与板载咪头移位

精确设计：`CanMV-K230-LP4-V3.0_20240509`。核验日期：2026-09-22。
本档案核对了官方工程中的音频相关连线、供电域及 K230 TRM 的 PDM 复用；
**未完成实物修订确认、焊接、录音或 AEC 验证**。不适用于庐山派、K230D 或其他 CanMV 修订。
产品索引见 [catalog](../../catalog/vendors/canaan/products/canmv-k230-v3p0.yaml)。

## 两条外置拾音路径

| 方案 | 硬件工作 | 软件影响 | 适合先解决的问题 |
| --- | --- | --- | --- |
| 原 MIC1 咪头移位 | 拆下原咪头，用短线接回原来的两个焊盘；保留主板偏置/耦合元件 | 可沿用原板载模拟采音路径，重新测增益与声学效果 | 主板藏在外壳内，咪头离声孔太远 |
| M5Stack Unit Mini PDM U089 | 通过 JP1 接四根线，不必拆 MIC1 | 改用 PDM 输入，核对时钟、双声道组与有效槽 | 需要独立模块安装，或希望避免拆焊主板咪头 |

如果现有板载采音功能正常，只需调整拾音位置，先试原咪头短线移位，集成工作较少。
若希望保留主板焊接状态，可先试 U089。两者的音质没有完成对比实测；板载不等于收音差，
数字麦克风也不保证更远的拾音距离。声孔、安装距离、腔体和扬声器泄漏都会影响结果。

## JP1 接 M5Stack U089

依据 [V3.0 原理图/PCB][v3-project]、[K230 TRM §11.1.6][trm] 和 [M5 官方 PinMap][m5]：

| U089 端 | 官方线色 | V3.0 JP1 **物理针号** | 板上网络 / 配置含义 |
| --- | --- | --- | --- |
| 5V | 红 | **1** | `VDD_5V`，模块电源 |
| GND | 黑 | **2** | `GND`；物理 4、37 脚也为地 |
| CLK | 白 | **19** | `BANK2_GPIO26` → `PDM_CLK`，K230 输出时钟 |
| DAT | 黄 | **15** | `BANK2_GPIO27` → `PDM_IN0`，K230 接收数据 |

这里是 **GPIO26 对应物理 19，GPIO27 对应物理 15**，不是把线接到物理 26/27。
JP1 是 2×20、2.54 mm 排针，**不能套用树莓派 40Pin 接线图**：本设计物理 1 是 5 V，
物理 2 是地。官方封装的 1 脚为方焊盘，其他脚为圆焊盘；从 1 脚沿同一排数为
1、3、5……，相对一排是 2、4、6……。俯视与背面焊接视角会镜像，不按图片左右猜针号。
接线前断电，以实际丝印、1 脚标记和对地通断复核；线色仅适用于对应官方线缆。

电压域与连接依据：

- U22 的 `R11` 是 `VDDIO_BANK2`，PCB 接 `VDD_3V3`；GPIO26/27 属于该域。
  U089 由接口 5 V 经 HT7333 生成 3.3 V，CLK/DAT 与该 IO 域匹配。5 V 只进模块电源端。
- U22 `U11`（GPIO26）与 JP1.19 同网；U22 `W13`（GPIO27）与 JP1.15 同网。
  PCB `PAD_NET` 中，这两个网络各只有 U22 和 JP1 两个器件端点，未见板载负载分支。
- TRM Table 11-6 明确 `PAD_IO_26` 的选择值 3 为 `pdm_clk`，`PAD_IO_27` 的选择值 3 为
  `pdm_in0`。CanMV 的功能名称是 `PDM_CLK`、`PDM_IN0`；应通过当前固件的 FPIOA API 配置，
  不把寄存器选择值 3 当成 Python 功能枚举值。
- U22 符号同时列有 GPIO26 的 `MMC1_CLK`，GPIO27 的 `MMC1_CMD` / `PULSE_CNTR5`。
  实际应用或外接扩展若已占用这两脚，必须先释放。上述板上连线核验不证明运行时引脚空闲。
- 单颗 U089 只需要这一组 CLK/DAT；不要照抄示例额外配置 GPIO34/35/36，避免影响 I2S 等用途。
  TRM 中 GPIO26/27 的 PDM 路线可与内部 codec 播放模式组合；最终并发能力仍要核对固件和资源。

### 采音配置边界

[CanMV v1.8 PyAudio][pyaudio] 的 PDM 输入使用 `input_device_index=1`，按 `channels // 2`
建立双声道组。单颗 U089 首轮应使用 **16 kHz、16 bit、channels=2**，读取第 0 组并确认
有效左右槽，再提取单声道；不要直接设 `channels=1`。模块 SELECT 接地，但这里尚未实测
该固件的有效 PCM 槽位，不建议把两槽未经检查直接混合。

该版本固定 64 倍过采样，16 kHz 对应 **1.024 MHz**，符合 SPM1423 的 1.0–3.25 MHz
工作时钟范围。直接设 8 kHz 会产生 0.512 MHz，低于规格。播放与录音应分别建立流。
更多软件约束和 AEC 原理见 [音频比较](../../docs/research/pdm-vs-max9814-audio-frontends.md)。
这些是源码推导的起始参数，没有在本板运行过；实际固件版本可能不同。

先采用短连接线，确保共地并让回流路径靠近时钟/数据线，检查时钟波形、PCM 和噪声。
当前没有核定 JP1 可供外设使用的剩余电流、U089 整板峰值电流或允许的最长线长，
不能据此把 PDM 当成可任意延长的远距离接口。

## 原 MIC1 咪头移位或同类替换

官方 `Peripherial` 页指定 **Goertek B4012AP422-003，两脚驻极体模拟咪头**。
其符号定义 1 脚为 `OUT`、2 脚为 `GND`，不是 PDM MEMS 模块。

| 原 MIC1 焊盘 | 电气含义 | 移位后的连接 |
| --- | --- | --- |
| **1（官方封装为方焊盘）** | 信号及直流偏置，网络 `$4N2560` | 接原咪头 1 脚，或已确认兼容咪头的 OUT / 正端 |
| **2（官方封装为圆焊盘）** | 地 | 接原咪头 2 脚，或已确认兼容咪头的 GND / 负端 |

信号焊盘通过 **R52 2 kΩ** 接 `MIC_BIAS`，经 **C171 4.7 µF** 耦合到 `MIC_PR`
（U22 F1，右路正输入）。该节点另有 **R53 2 kΩ** 与 **C172 10 nF** 分别到地；
`MIC_NR`（U22 F2，右路负输入）经 **C173 4.7 µF** 到地。元件值来自原理图，
连接来自 PCB 网络；这不是对实物装配值、偏置电压或 PCM 声道顺序的测量。

因此移位时只延长 **咪头到原焊盘的两根线**，保留上述元件，不额外给咪头接 3.3 V/5 V，
也不把这两个焊盘当作普通 GPIO。推荐顺序：

1. 原位先录一段基线；断电，记录咪头方向、焊盘和引脚对应关系，再拆下原咪头。
2. 用短的屏蔽线，或信号/地绞合线接回。可先试 **5–10 cm**，这是首轮试验建议，
   不是厂商规定的最大线长。用绝缘及应力固定避免拉扯焊盘。
3. 把咪头声孔对准面板透声孔，留出透声通道，避免胶堵声孔；与扬声器尽量隔开并做隔振。
   模拟线避开开关电源、继电器/锁驱动和扬声器大电流走线。
4. 复查极性、短路和对地通断后上电，用相同采样参数、位置和音量比较噪声、语音和削顶。
   先关闭或固定自动增益/降噪做原始录音比较，再调 AEC。

如果不想复用原咪头，优先用**同型号 B4012AP422-003**；其他两脚驻极体型号须比较
工作电压、电流/负载、灵敏度、极性、声孔方向和尺寸。不能仅凭“两根线”认定可平替。
原 MIC1 应断开后再替换，不把两只裸咪头直接并联在同一偏置节点。

**U089 不能替换到 MIC1 两个焊盘上**：它需要电源、地、数字 CLK/DAT。MAX9814 模块的
放大后 OUT 也不能当裸咪头直接替换，需另做偏置、隔直、幅度及输入增益匹配。

## 上板验证与恢复

- 记录实物 V3.0 修订、咪头/模块身份、固件提交、供电、线长、外壳、距离、音量和测试时长。
- 比较原位、移位或 U089 的安静底噪、近远讲话、风噪、削顶及扬声器泄漏。
  AEC 使用一只咪头加实际播放参考即可；仍需测近端单讲、远端单讲和双方同时讲话。
- 组合摄像头/KPU、显示、网络、存储负载后检查掉音、延迟与复位。只有 PCM 非零不算验收。
- 移位方案的恢复点是原 MIC1 两焊盘及原安装方向；PDM 方案的恢复点是拔掉模块并恢复原
  引脚复用/采音配置。拆焊有损伤焊盘的可能，不视为无损改装。
