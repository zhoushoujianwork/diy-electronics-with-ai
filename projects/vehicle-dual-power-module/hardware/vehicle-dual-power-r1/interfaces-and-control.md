# 接口与控制合同 R1-BAT

这是硬件接口和后续固件的实现要求。本阶段没有实现STM32或Atom固件。
本 R1 合同仅覆盖 BAT 3.9V 输出；拟增 VIN 5V/2A 人工选择模式见[下一版设计输入](../../docs/power-output-modes.md)，当前端子和控制表不得据此解读为已具备 VIN 供电。
端子编号以下表和元件库焊盘号为准；不要从插头出线侧猜测左右顺序。

## 接口

| J101 | 5.00mm螺丝端子3P | 1车载正极；2GND；3ACC | 输入近电瓶处/点烟器插头内另有合适保险丝 |
| J102 | 2.54mm排针2P | 1车载正极；2ACC | 点烟器模式用短路帽连接；独立ACC模式不装短路帽 |
| J201 | XT30PW-M | 1负极；2正极；3、4固定脚无网络 | 电池线端用配套母端，先核对极性；禁止带负载插拔 |

输出端子不构成多路独立电源，插满所有端子不会增加电流能力。
电源线路使用额定端子及合格压接线，回路总电阻≤60mΩ作为计算预算；短线建议主控≥AWG22、Tiny≥AWG20，具体长度按实测回路电阻核对。
XH实际间距2.50mm，排针2.54mm，不能混用封装或插壳。
后续PCB须用文字和不同位置区分5V/3.9V；本阶段没有PCB丝印或机械防呆验证。

### Tiny接线

`J305.1 → Tiny BAT`，`J305.2 → Tiny GND`；也可选同路螺丝端子或排针。
`J308.3 → Tiny RXD`，`J308.4 ← Tiny TXD`，`J308.2 → Tiny GND`。
Tiny **VIN、EN留空**，J308.1不接Tiny。不得同时从Tiny USB、VIN或其他电池给Tiny供电。
用BAT供电能否自动启动、上电后TXD电平及4G发送脉冲，均列入首板测试。

### AtomS3 Lite接线边界

主控使用本板受控5V和GND。主控3.3V仅作为两组TXU0202的参考输入，不由本板直接灌入Atom的3.3V轨。
具体Atom扩展脚号和UART GPIO分配留给该板精确版次的接线/固件任务；本板输出不是12V，不能把车载输入直接接Atom。
正常运行不另接供电USB；调试用隔离VBUS的数据线或相应硬件隔离。
StickS3自带电池仍可能维持运行，需额外处理其内部电源管理。

| PA0 / PA1 / PA4 / PA5 | BAT_SW / CAR_5V / HOST_SW / TINY_BAT ADC，均分压1/3 |
| PA2 / PA3 | USART2 TX / RX，电源管理协议 |
| PA6 | CTL_CAR_EN |
| PA7 / PB0 | 主控 / 4G稳压器使能 |
| PB1 / PA8 | 主控 / 4G负载开关使能；同时控制对应UART OE |
| PA9 | 允许充电，经NMOS转换为CE#低 |
| PA10 | 充电状态STAT# |
| PA11 / PC15 | 主控 / 4G切换器选源状态；高代表车载支路被选用 |
| PA12 / PA15 / PB3 | ACC_N / KEY_N / EXT_WAKE_N，低有效 |
| PB4 | LIS2DW12 INT1，配置为推挽高有效 |

内部时钟，不装外部晶振。BOOT0下拉；所有功率使能有硬件下拉，MCU复位即关负载。
ADC有100nF滤波，RC约6.7ms；上电采样至少等待约35ms，并校准内部参考。断电快速保护不能依赖一次未经滤波的读数。

## 状态与优先级

1. **MASTER_OFF**：最高优先级。车载与电池MOS均由机械触点硬件关闭，充电、AON及负载停止；任何固件请求无效。储能电容仍需放电。
2. **FAULT/LOW_BAT_LATCH**：关4G、关主控并禁止自动运动唤醒；保持能工作的AON。恢复条件明确满足后才尝试一次启动。
3. **MANUAL_OFF**：按键长按触发的关机完成态。屏蔽IMU及外部唤醒；按键或一次完整ACC关闭再开启才启动。
4. **PARK_STANDBY**：ACC关且连续静止120s后的关机完成态；允许IMU、外部唤醒、按键、ACC启动。
5. **STARTING / RUNNING / SHUTDOWN_PENDING**：按下述顺序执行。

总开关恢复ON：先保持所有输出关闭，初始化控制器和传感器，读取ACC；ACC有效则开机，否则进入停车待机。
无电池时AON由车载独立LDO供电，按键与ACC都能触发上述流程。
点烟器完全断电且未装电池时不存在待机电源，无法运动唤醒。

### 开机顺序

1. 去抖按键20ms；确认没有锁存的硬件故障。此时不能以BAT_SW低电压直接拒绝开机，因为可能未安装电池。
2. 先使能主降压器以探测车载供电；等CAR_5V进入4.80～5.35V并稳定100ms，最长等待1s。本板没有VEH_PROT ADC，ACC也不等于车载主电源存在。探测失败则关闭主降压，仅在电池满足启动条件时继续；两者均不满足则返回待机/低电量锁存。
3. 使能主控稳压器；等PG有效且电压合理50ms，最长等待500ms。
4. 使能主控负载开关，启用管理UART；等待主控HELLO，最长5s。
5. 使能4G稳压器，PG稳定50ms后使能4G负载开关及数据UART；Tiny启动后由主控做AT检测。
6. 电池支路在RUNNING期间保持可切换；不能等车载断电后才启动备用稳压路径。

启动失败关负载并上报/记录原因；禁止无延时反复拉起4G。无主控HELLO时关闭两路，等待新的人工/ACC事件。

### 关机顺序

运行时按住电源键约2s，发送带序号的关机请求。主控保存数据、停止通信并回复相同序号的ACK。
收到ACK或10s超时后，先关4G负载和UART，100ms后关主控负载及UART，再关两个稳压器。
ACC仍有效时可以维持车载降压与充电；ACC无效则关闭主降压和充电，进入相应的待机状态。
长按事件只触发一次，释放按键后才重新接受下一次事件。

直接拨MASTER_OFF立即切断硬件，不等待ACK。日常先按键关机再拨OFF。

### 电量与运动唤醒

- 以下低电池关机条件适用于任一路负载正在使用电池、或车载主降压已失效的情况。两路均由合格CAR_5V供电时，缺电池/低电池只报告为备用电源不可用，不能切断正常车载运行。
- 依赖电池时，BAT_SW低于约3.60V持续1s请求电量关机；先停4G以减少脉冲负载。
- 依赖电池时，BAT_SW低于名义3.45V持续20ms进入低电量锁存，快速关闭负载；这是普通10s保存等待的保护例外。
- ADC误差应在校准后保证实际切断不低于设计的3.40V边界。电池保护板提供最终过放保护。
- 低电量后不因电压回弹自动恢复运动唤醒。车载5V合格并稳定500ms可恢复；人工按键需电池≥3.75V稳定60s才允许一次重试。
- 外部WAKE_N仅低压开漏，低20ms确认；保持低不会重复触发，释放20ms后重新布防。手动关机期间忽略。
- 停车运动阈值需按实车振动标定，建议初始约100mg、连续约160ms；这些是固件调试初值，非已验证防误报参数。
- 静止120s期间任何有效运动重置计时。运动唤醒后的工作窗口由主控请求结束，或重新满足静止条件后结束。

## 管理UART协议草案 v1

3.3V主控侧 / 3.0V AON侧，115200、8N1、无流控。两端独立上电后重新握手。
帧为ASCII：`@序号,类型,参数*CCCC\r\n`，序号0～65535；整帧≤96字节。
CCCC为4位十六进制CRC-16/CCITT-FALSE（多项式0x1021，初始0xFFFF），计算范围为`@`之后、`*`之前的ASCII字节。

| 方向 / 类型 | 参数与含义 |
|---|---|
| 主控→AON `HELLO` | `1`，协议版本；回复`STATUS` |
| AON→主控 `SHUTDOWN` | `KEY` / `PARK` / `LOWBAT` / `FAULT`，开始最长10s流程，保护紧急关机除外 |
| 主控→AON `ACK_OFF` | 对应SHUTDOWN序号，表示数据保存和通信停止完成 |
| 主控→AON `GET_STATUS` | 无参数 |
| AON→主控 `STATUS` | 状态、ACC、BAT_mV、CAR_mV、HOST_SW_mV、TINY_mV、充电状态、唤醒原因 |
| 主控→AON `MODEM_OFF` / `MODEM_ON` | 独立控制4G，仍受故障/电量条件限制；回复`ACK`或`ERR` |
| AON→主控 `WAKE` | `KEY` / `ACC` / `IMU` / `EXT` / `MASTER_ACC`，上电握手后报告 |

坏CRC、过长帧和不匹配ACK均丢弃；部分帧超时100ms清空。关机请求可每500ms重发，序号和截止时刻保持不变。
断电动作不依赖UART发送、文件系统或主控心跳完成。独立看门狗故障复位后所有输出默认关闭。

## 掉电接口约束

TXU0202的Ioff用于管理及Tiny串口。外部唤醒只能使用本板AON供电或真正开漏且无外部上拉的传感器。
SWD有串联电阻，**没有自动掉电隔离**：调试器必须遵守VTREF=0时全部信号高阻，或验收时拔除调试器。
这些要求是接口合同，不能把电阻限流当成已阻止反灌；在验收中分别测AON与两个输出残压。
