## 布局失败的边界

工具为easyeda-agent 1.8.0，宿主Web EasyEDA Pro 4.1.60。v1固定测量朝向，v3将供电轨设为
`local_power`并允许二端外围旋转，v4扩大有界搜索，v5对部分失败区允许更多外围朝向。
v6明确总开关限流电阻链的归属后该区通过；v7把同一芯片的并联电容组和ADC滤波支路明确为连接链。
所有版本保持同一引脚网络、明确NC和功能区归属；v6/v7只细化区内附属关系。跨区控制信号仍为`module_port`，已声明的外围连接仍需真实导线。

`candidate-budget-exhausted`、`expanded-node-budget-exhausted`或`final-validation-failed`只说明该次工具求解没有产生完整合格结果，
不能据此认定电路无法绘制或A4容量不足。成功的局部结果也不是完整页面；若使用了新朝向，必须先回读其真实文字/引脚几何再重算。

所有原始输入、报告和候选保存在本地`build/layout-v*/`，摘要对原始字节做SHA-256绑定。
`source/layout-attempt-inputs/`保留用于重现的参数输入；未提交含账号信息的原生工程内容或第三方数据手册。

最终有17/27区得到局部完整结果，10区尚未解决。百万候选的完整失败记录与后续附属关系修正仍未收敛到四页完整方案。
其余重复计算在整理检查点时停止；这些记录单独标为`interrupted-no-result`，不冒充工具返回的失败或证明无解。
继续实施需先解决这些区的局部直连/标记求解，再完成朝向实测、合页和受保护Apply；当前未生成可制板网表。

本地原生备份位于`raw/checkpoint-20260928/motobox-power-r1-unwired.epro2`，323124字节，ZIP完整性已验证；
SHA-256为`25ba7cd4df897bcddfbf67c06715c210470b6453616712c014c5ebfb842bc50f`。
它包含未布线测量状态，未做重新导入验证，不能作为完成态原理图。

### 功能归属复核

- 车载保护区的LM74800和两只MOS属于同一反接/断开回路；电池区的XT30、保险丝和MOS对属于完整的双向隔离回路。
- UART隔离器和对应连接器同区，保证信号方向可以整体核对；多引脚成员提示不意味着存在多个应拆分的独立电路。
- `rail-only-attachment`中的电容由芯片具体电源脚或稳压输出指定；输入/输出去耦不能因同名电源轨而转归其他芯片。
- 放宽绘图姿态或增加搜索预算不放宽碰撞、真实直连、身份、NC、图框或文字检查。

## 实板验收记录格式

每次记录：PCB/装配版次、实际BOM偏差、电池型号与保护板、NTC型号及安装位置、Tiny精确板版次、
Atom型号、固件提交、仪表型号/设置、电源与线束布置、环境/电芯温度、持续时间、原始波形位置和判定结果。
没有固件的项目可先用受控信号源模拟使能；结果明确标为电源硬件单项测试。

| 项目 | 条件与步骤 | 通过条件 |
|---|---|---|
| 上电前核对 | 核对每只芯片1脚、MOS体二极管、XT30极性、NTC、锡桥；限流电源首次上电 | 无错装/短路；使能默认低；Tiny VIN与外部USB没有连接 |
| 两路持续负载 | 电池与车载分别供电；主控1A、Tiny2A，先室温30min，再覆盖声明环境范围 | 负载端主控4.75～5.25V、Tiny3.4～4.2V；无限流震荡，器件/电芯不超规格温度 |
| 低电量能力 | 逐步降低BAT_SW至3.40V，覆盖满载及启动 | 稳压范围成立，或在跨界前受控关断；不能在未声明条件下反复重启 |
| 4G脉冲与切源 | 真Tiny注册、联网和连续上传，同时反复移除/恢复车载输入；记录BAT、两路输出、PG、UART | 不复位、不丢失供电；Tiny BAT最低不低于3.4V，主控最低不低于4.75V；无回灌或过冲 |
| 无电池冷启动 | 拔掉电池、保留车载；分别用ACC和按键启动，至少20次 | AON先工作，主降压建立后两路按序上电；不因ADC_BAT=0误判而拒启 |
| BAT自启动 | Tiny仅接BAT/GND和受控UART；VIN/USB/EN留空 | 上电后可完成AT握手、注册和上传；若需额外PWRKEY，此版本接口需修改后重验 |
| 充电温度窗口 | 热箱/温控台与NTC电阻替代法各测一次；开路和短路故障也测 | 低于0°C及高于45°C禁止充电；实测边界符合容差计算；正常区电流/电压符合电芯规格 |
| 软关机与超时 | 正常ACK、错误序号ACK、坏CRC、主控无响应分别测试 | 按键2s触发；正确ACK后断电，无ACK最长10s；4G先关、主控后关；独立控制器保持可唤醒 |
| 手动关机屏蔽 | 手动关机后触发板上IMU与外部唤醒；随后按键或ACC关闭再开启 | IMU/外部口不重启；按键或新的ACC沿可启动 |
| 停车与外部唤醒 | ACC关、静止120s；IMU、外部低脉冲、保持低、释放再触发分别测试 | 20ms去抖与释放重布防成立；持续低不重复唤醒；静止时间中有运动会重新计时 |
| 硬件总开关 | 运行/充电/主控失联/AON MCU停住时分别直接拨OFF | 两路负载、AON、充电均停止，按键/ACC/IMU无法启动；记录各轨电容放电时间与残压 |
| 反灌与残压 | 分别测试主控USB、UART、外部唤醒及符合VTREF协议的调试器组合 | 信号不使AON或另一负载上电；USB供电主控本身继续运行属于已声明边界；调试器违规注入须阻止使用 |
| 低电量迟滞 | 电池供电下降至阈值后去负载，观察回弹；再施加车载或人工恢复条件 | 电压回弹不自动反复启动；无电池车载运行不被低电池逻辑切断 |
| 开关循环 | 按键与总开关分别至少20次，混合车载/电池 | 无锁死、重复上电、反灌、设置丢失或异常充电 |
| 七天静置 | ACC断、负载关、带实际保护板和外部传感器；断开调试器；记录电池侧积分电流168h | 目标平均≤0.2mA，验收≤0.5mA；记录温度、自放电和意外运动唤醒，不能用AON LDO单项电流替代整机 |
| 车载瞬态 | 先定义反接、启动跌落、24V误接、浪涌的幅值、源阻抗、持续时间与次数，再受控测试 | 只对实际通过的条件声明耐受；SMBJ33CA及部分Q1器件不自动等于整板车规认证 |

退回点：原StickS3直连原型和固件保持不变；当前独立电源工程不得用于替换其已验证供电，直至原理图与上述相关硬件验收完成。
