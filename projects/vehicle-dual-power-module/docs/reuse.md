# 其他项目接入约定

本文件给出项目级边界；**现有 R1 源数据只覆盖 BAT 输出，VIN 5V/2A 仍是[待落图的设计输入](power-output-modes.md)**。已存在的位号、针脚与控制状态机统一维护在[接口与控制合同](../hardware/vehicle-dual-power-r1/interfaces-and-control.md)，避免项目之间复制后出现不同版本。

## 供电与线束

| 接口 | 接入条件 |
| --- | --- |
| 车载输入 `J101` | 车载正极、GND、ACC；点烟器模式按接口合同使用 `J102` 跳线。靠近电源处另设合适保险丝；车载浪涌耐受尚待实测。 |
| 外部电池 `J201/J202` | 仅接已核对极性的受保护 1S 电芯与贴附 NTC；XT30 功率端与 NTC 插座分开。 |
| 主控 5V `J301–J303` | 三种接线端子任选或并用，**合计 1A**。正常整机供电只经本板；调试 USB 要隔离 VBUS。 |
| BAT `J304–J306` | 现有三种端子合计 **2A**，名义约 3.9V。连接适用模块的 BAT/GND；不可同时给该模块的 VIN、USB 或其他电池供电。 |
| VIN `J309–J311`（预留位号） | 拟增三种端子合计 **2A**，5V 类输出。尚未在 EDA 放置或验证，**当前板不能从此处取电**；只接适用模块的 VIN/GND，不与 BAT 线束同时安装。 |
| 外部唤醒 `J401/J402/J404` | `3V0_AON/GND/WAKE_N`；WAKE_N 为低有效开漏，三个端口并联。外设供电总预算 10mA，七天待机目标要求实际传感器约 ≤50µA。 |
| 管理串口 `J405/J406` | 主控 3.3V 参考输入、GND、TX、RX；经掉电隔离与 3.0V 常供电控制器通信。与主控到 Tiny 的数据串口分开。 |

端子载流、压接质量与线长均应核算；设计以回路总电阻 ≤60mΩ 做压降预算。XH 插座节距是 2.50mm，不能用 2.54mm 排针插壳代替。连接器朝向以焊盘编号和最终丝印为准；当前无 PCB 可核验。

## 控制集成

- 外壳电源键接本板 `J403`，与板上按键并联；不依赖 AtomS3 Lite 或 StickS3 自带按键。
- 下一版通过低电流开关人工选择 BAT 或 VIN 供电支路；电源板不读取 Tiny 型号或检测所接电源脚。改变选择前先总开关 OFF 并等待输出残压消失。
- 总开关 OFF 通过硬件关闭车载与电池路径，立即中断运行。日常按键长按约 2 秒，给主控最多 10 秒保存和确认，再按顺序切断 Tiny、主控。
- ACC 关闭并持续静止 120 秒后进入停车待机，允许 IMU、外部开漏、按键或 ACC 唤醒。手动关机会屏蔽运动和外部唤醒。
- 主控应实现[管理 UART 协议草案](../hardware/vehicle-dual-power-r1/interfaces-and-control.md#管理uart协议草案-v1)并为保存数据/结束通信发 ACK。协议与电源板 STM32 固件当前都还没有实现。
- AtomS3 Lite 的精确输入脚和 UART GPIO、StickS3 内置电池及其 PMIC 行为，需要由接入项目分别验证；本模块的输出切断不能自动证明带内置电池主控已关机。

若要在另一项目中使用，引用本项目的[设计版次](../hardware/vehicle-dual-power-r1/README.md)、[接口合同](../hardware/vehicle-dual-power-r1/interfaces-and-control.md)和[验证范围](validation.md)，并记录该项目的主控版次、负载模块版次与所接电源脚、电池/线束、固件提交和实测条件。
