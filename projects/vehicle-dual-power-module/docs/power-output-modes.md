# 4G 供电双模式设计

电源板只提供电压和受控通断，**不识别 Tiny 或其他外设**。装配时人工选择一种供电线束：约 3.9V/2A 输出接支持此范围的 BAT 输入，或标称 5V/2A 输出接支持此范围的 VIN 输入。两路不是可叠加的 4A 负载，不得同时接到同一个模块；模块若还有 USB 或内部电池供电，接入项目需另行处理反灌。

| 模式 | 并联端子，三口合计限流 | 电路路径 |
| --- | --- | --- |
| BAT | `J304/J305/J306`：螺丝、XH 2.50mm、排针 2.54mm；合计 2A | 车载/电池切源 `U203` → 约 3.9V 稳压 `U304` → 输出开关 `U305` |
| VIN | `J309/J310/J311`：螺丝、XH 2.50mm、排针 2.54mm；合计 2A | 独立车载 6.52V/电池 6.56V 前级 → `U308` 切源 → `U310` 约 5.08V 稳压 → `U309` 输出开关 |

`SW301` 双刀开关分别选择稳压器和负载开关的低电流使能请求。BAT 档为触点 1–2、4–5；VIN 档为 2–3、5–6。未选支路的使能脚各有硬件下拉。开关不承载 4G 电流，控制器也不读取档位。换档前应先关闭总开关、拔掉模块线束并等待输出电容放电；触点方向、断开瞬态和残压须在实板核对。两个电压档的 4G UART 共用低静态电流 `U306` 提供的参考电源，收发器 OE 随负载请求关断。

这两个输出目前只存在于**未布线的电气源数据和测量区器件**。EasyEDA 工程有 299 件已放置元件，VIN 新增 78 件经保存重载和脚位回读；没有可制板的完成态原理图。VIN 电路引脚、嘉立创 C 号及压降核算见[原理图 R2 依据](vin-schematic-r2.md)和[计算记录](../hardware/vehicle-dual-power-r1/vin-calculations.json)。在 2A、热态开关压降及暂定线束回路下，端点典型估约 5.00V；按芯片 FB 极值和 1% 反馈电阻极值，估算范围约 4.79～5.30V，尚不能保证全条件 5V±5%。接入方必须核对模块 VIN 上下限和启动/发送脉冲。

电池供电初算按加载电压不低于 3.0V、VIN 末级效率 90%、升压效率 85%：VIN 满载与主控 5V/1A 同时运行时约需 6.39A 电池电流。保护板、线束、MOS、保险丝温升和电芯低压下的实际限流须实测。低电压关断与恢复迟滞仍由未来 STM32 固件实现；当前没有固件或实板验收。
