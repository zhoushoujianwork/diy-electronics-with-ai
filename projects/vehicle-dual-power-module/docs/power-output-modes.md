# 4G 供电双模式设计输入

## 决定与当前实现

电源板只提供电压和受控通断，**不识别 Tiny，也不自动判断外设接了 BAT 还是 VIN**。装配时人工选择一种供电线束：现有约 3.9V / 2A 接 BAT，或新增的 5V 类 / 2A 接 VIN。不得把两路接到同一模块，也不得同时接模块 USB、电池或其他供电源。两种输出不是可叠加的 4A 负载。

**截至本版，四页 EasyEDA R1 源数据只有 BAT 3.9V 支路；以下 VIN 支路尚未放置器件、布线或完成 BOM。** 它是下一版原理图的设计合同，不是现板已经具备的接口。主控 5V / 1A 保持独立。

| 供电方式 | 预留接口 | 目标负载 | 配置 |
| --- | --- | --- | --- |
| BAT | 现有 `J304/J305/J306`：螺丝、XH 2.50、排针 2.54 | 约 3.9V / 2A，三口合计 | 外部线束只接适用模块的 BAT/GND；当前 R1 源数据覆盖此方式 |
| VIN | 拟增 `J309/J310/J311`：螺丝、XH 2.50、排针 2.54 | 5V 类 / 2A，三口合计 | 外部线束只接适用模块的 VIN/GND；待下一版落图和实测 |

端子要以**不同位置和明显的 `BAT 3.9V` / `VIN 5V` 丝印**区分；相同节距的插头本身不防误插。拟增加一个低电流双刀选择开关 `SW301`，分别把原有 4G 稳压器使能和负载开关使能送往 BAT 或 VIN 支路，未选支路由硬件下拉保持关闭。开关只选择电源路径，不读取模块身份。改变位置前先将总开关拨 OFF、拔下模块线束并等待输出电容放电；开关触点与残压的互斥行为要在首板验证。主控管理协议中的 `MODEM_ON/OFF` 仍只表示所选 4G 支路的开关请求。

## VIN 支路待落图电路

保留现有 `U203 TPS2117 → U304 TPS63020 → U305 TPS22965 → BAT`。新增的 VIN 供电使用**两条专用输入支路**：

```text
车载 VEH_PROT → 新增 5.4V 降压器 ──────┐
                                      ├→ 新增 TPS2121 车载优先切源 → VIN 负载开关 → J309–J311
电池 BAT_SW → 新增 TPS61088-Q1 升压器 ┘
```

这样车载 VIN 满载不挤占原 `CAR_5V` 降压器给主控与充电器的电流额度；电池升压器也不经过原 4A 的 `U203`。VIN 工作时两条前级保持就绪，供 TPS2121 在车载掉电时切换。不能用一个升压器直接接在 `MODEM_SRC` 后：车载输入约 5.088V、目标 5V 类输出过于接近，升压器的最小导通时间与直通行为不能证明该条件下稳定调压。`TPS63020` 产品页给出的 2A 输出条件是 **3.3V 输出**，不能据此保证本项目的 5V/2A 低电池运行。

候选嘉立创身份：新增车载降压器 `TPS54560BQDDAQ1 / C1355305`，电池升压器 `TPS61088QRHLRQ1 / C1850341`，切源器 `TPS2121RUXR / C485916`，VIN 负载开关可评估 `TPS22976DPUR / C2680350`（目录有货但为双通道，未用通道需逐脚处理）；电感先复核 `XAL5030-222MEC / C920280`。这些是**待放置和核对的候选**，并非已完成 BOM。补偿、频率、限流、输出电容、软启动及真实库符号脚位仍需按手册逐项确定。

两条 VIN 前级拟以 **5.42V 名义目标**做压降分析。它是专供允许 5V 类 VIN 输入的待验证设定，**不是通用 USB 5V 输出**。TPS61088-Q1 的反馈参考在 PWM 模式为 1.186～1.222V，名义 1.204V；所需上/下反馈电阻比约 `5.42/1.204−1 = 3.502`。以车载前级合计 −3.1%、TPS2121 56mΩ、负载开关 30mΩ、线束回路 30mΩ 的设计分配估算，2A 时模块端最低约 `5.42×(1−0.031)−2×(0.056+0.030+0.030) = 5.02V`。56mΩ 是切源器的典型值，不是热态保证值；选定最大导通电阻、车载降压容差和线束后必须重算。5.42V 的正向容差与启动过冲还必须保持在所选负载开关额定输入范围内；不能将此预算当成已保证的输出范围。

## 两种输入源下的功率约束

下表用 VIN 前级 **5.42V × 2A = 10.84W**、电池升压效率 **80%**、主控稳压效率 **85%** 的设计分配计算。效率和电阻温升均待实测；电池 VIN 支路电流先按 `Pout/(η×BAT_SW)` 估算，尚未加入电池 MOS、保险丝及铜箔造成的额外压降。主控同时满载 1A。

| 条件 | 离线估算 | 设计结论 |
| --- | --- | --- |
| `BAT_SW=3.40V` | VIN 升压输入约 **3.99A**；加主控约 **5.83A**，原电池隔离 MOS 对按现有热分配约 **1.41W** | 输入电流不经过原 4A 切源器，但电池 MOS、保险丝、铜箔、升压电感与保护板须按此条件和启动脉冲重新选型/测温 |
| `BAT_SW=3.60V` | VIN 升压输入约 **3.76A**；加主控约 **5.5A**，电池 MOS 对约 **1.26W** | 可作为 VIN 模式先行关断候选点，留出电芯压降与热裕量；阈值须与真实效率/热测试一起冻结 |
| 车载输入、两路满载、允许充电器约 0.77A 输入 | 原 `CAR_5V` 降压器仅承受主控约 **1.21A** 加充电器约 **0.77A**；新增 VIN 降压器独立承担约 **2A** | 不把两路负载和充电叠到同一 4A 降压输出；仍需核算共用车载保护、输入保险丝、两只降压器的热和瞬态 |

R2 控制器**不读取选择开关**，因此低电量策略按两种输出中更重的 VIN 负载统一设计：初步建议 `BAT_SW ≤3.60V` 持续 1 秒请求关机，≥3.85V 稳定后才允许一次人工重试；紧急保护阈值、滤波和恢复条件还需重新计算。它只测电池和电源轨，**不检测 Tiny**。比较器/控制器故障下的默认关断、开关触点切换、3.6V 临界瞬态和电池保护板限流仍需在原理图和首板中落实。

## 落图与验收门槛

1. 按实际嘉立创库符号读取新增车载降压器、TPS61088-Q1、TPS2121、选择开关、VIN 负载开关与端子引脚，再冻结 C 号、封装和完整 BOM；不得从芯片数据手册脚号猜 EDA 符号脚位。
2. 更新四页源数据、物理器件、线网和 NC，核对 `SW301` 对两路 EN 的互斥、未选支路下拉、VIN 端子极性及各输入源的优先级；同步改写统一低电量阈值。重新计算待机漏电、5.42V 高端容差和车载/电池热预算。
3. 完成原理图布线、DRC、保存重开回读；之后实测 BAT 和 VIN 两种模式的车载/电池满载、4G 脉冲、切源、模式错误接线、残压和至少 20 次切换。Tiny 的精确 VIN 范围、启动行为和 USB/电池互斥需由接入项目核对版次。
