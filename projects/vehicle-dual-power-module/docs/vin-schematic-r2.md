# 可选 VIN 5V/2A 支路：原理图 R2 设计依据

这路输出供允许 5V 输入的外接模块使用；约 3.9V/2A 的 BAT 输出与它由用户**断电后换线选择**。电源板不识别模块型号；两路端子不可同时接到同一模块。`SW301` 只切换低电流使能，不承载负载电流。

四页 EasyEDA 工程现有 299 件器件，其中 BAT 原方案 221 件、VIN 新增 78 件。VIN 的 8 件核心及端子和本轮 70 件外围均已放置、保存、重载并回读脚位；见[外围回读](../hardware/vehicle-dual-power-r1/r2-vin-peripherals-checkpoint.json)。这些器件仍在纸外测量坐标，**所有页面仍为零导线**，不能按当前图面制板。

## 电源链与控制

```text
车载保护后 ── U105 6.52V 降压 ──┐
                              U308 TPS2121 ── U310 约 5.08V 稳压 ── U309 输出开关 ── VIN 端子
电池总开关后 ── U206 6.56V 升压 ──┘
```

| 页与功能 | 关键元件及嘉立创 C 号 | 目标连接 |
| --- | --- | --- |
| 1：车载前级 | `U105` TPS54560BQDDAQ1 / `C1355305`；`L102` 6.8µH / `C3911753` | VIN=`VEH_PROT`；BOOT 经 100nF 到 SW；SW 经续流二极管、电感到 `VIN_CAR_6V5`；71.5kΩ/10kΩ 反馈设约 6.52V。 |
| 2：电池前级 | `U206` TPS61088QRHLRQ1 / `C1850341`；`L202` 744311150 / `C1332206` | VIN=`BAT_SW`；FSW 的 249kΩ **接 SW**；BOOT 经 100nF 接 SW；249kΩ/56kΩ 反馈设约 6.56V；60.4kΩ ILIM、47nF SS；NC11/12 依 TI 建议连地平面，MODE 悬空采用轻载 PFM。 |
| 3：切源 | `U308` TPS2121RUXR / `C485916` | IN1/IN2 分别接车载/电池 6.5V。PR1、CP2 分压形成车载优先 XCOMP 快切；OV1/OV2 典型阈值约 8.64V；ILM 30kΩ 对应典型约 3.49A；SS 100nF。 |
| 3：5V 稳压 | `U310` TPS54302DDCR / `C311983`；`L303` 6.8µH / `C3911753` | 输入 `VIN_SRC`；BOOT 经 100nF 接 SW；100kΩ/13.3kΩ 反馈设典型约 5.08V，75pF 前馈。 |
| 3：输出断开 | `U309` TPS22811LRPWR / `C17294173` | IN=`VIN_5V_REG`，OUT=`OUT_VIN_5V`；EN/UVLO 有 100kΩ 下拉；EN#/OVLO、PGTH、IMON 接地，DVDT 接 1nF，PG 和 DNC 悬空。 |
| 3：人工选择与端子 | `SW301` / `C225088`；`J309/J310/J311` / `C474881/C2908600/C492401` | BAT 档把两路主控请求送给 BAT 稳压与开关；VIN 档送给两个 6.5V 前级、5V 稳压及输出开关。三种端子并联，**合计** 2A。XH 为 2.50mm，排针为 2.54mm。 |

管理 UART 的 3.3V 参考电源 `U306` 改由 `AON_RAW` 供电，以便 BAT、VIN 两档共用；收发器 OE 在关机时默认关闭。外接模块的 UART 电平和关机反灌仍需逐型号核对。

## 参数核算与限制

[计算文件](../hardware/vehicle-dual-power-r1/vin-calculations.json)列出假设和结果。5V 稳压级典型输出为 5.077V；在 2A、负载开关热态 8.4mΩ、线束与端子回路暂分配 30mΩ 时，端点约 **5.00V**。按 TPS54302 的 FB 范围及 1% 电阻极值，端点低端约 4.79V、高端约 5.30V。因此目前只能标称 **5V/2A 设计目标**，尚不能承诺全温度、全线束条件下满足 5V±5%；接入方须核对模块的 VIN 允许范围。

按最低加载电池电压 3.0V、末级效率 90%、升压效率 85%、电感最小值按 −30%、最低开关频率 500kHz 估算，升压电感峰值约 5.97A。60.4kΩ ILIM 对应开关限流典型 9.11A，按 TI 的最坏差异估约 7.81A。主控 5V/1A 同时运行时电池总电流估约 6.39A，低于所选电芯至少 9A 连续放电目标。电池压降、保护板阈值、启动浪涌、热及环路裕度仍须测量。
