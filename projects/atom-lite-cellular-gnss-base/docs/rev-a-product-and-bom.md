# 首版产品目标与器件选型

日期：2026-09-27。范围收敛与选型记录；整板电气设计尚未冻结。

## 我们做什么

做一款 **ATOM Lite 的 Tiny 4G 适配底座**，与外接 GPS Unit 组成定位上报设备。
自己设计一块载板和打印外壳，复用 ATOM Lite、Tiny 通信核心板与 GPS Unit。
载板负责 Type-C 供电分配、主机与 Tiny 的连接，以及确有需要的控制/电平适配。
SIM、蜂窝基带和射频由 Tiny 承担；定位由现成 GNSS 接收器承担。

首次完成 SIM/APN、服务端凭据和设备绑定后，日常使用为：
**插入 Type-C → 自动联网 → 上报在线状态 → 获得有效 GNSS 位置后持续上报。**
上电自动运行需要固件与 Tiny 自启动电路共同实现；取得有效位置还取决于天线和接收环境。

| 项目 | 首版选择 |
| --- | --- |
| 主机 | ATOM Lite C008 |
| 蜂窝 | 芯引者 ML307R-DL Tiny；板级供电/电平待取得资料 |
| 定位 | 外接现有 M5Stack Unit GPS v1.1 / U032-V11 |
| GNSS 入口 | 优先复用 ATOM 自带 Grove，G26 为主机 TX、G32 为主机 RX；接线前核对电平与线束 |
| Tiny 串口 | ATOM 底部 G19 为主机 TX、G22 为主机 RX；独立于 GNSS UART |
| 供电 | 底座 Type-C 5 V 单输入，分别供 Tiny 与主机；GPS 随主机支路供电 |
| 自制件 | 一块 ATOM 适配 PCB、对应打印壳；Tiny 独立壳仍沿用已记录基线 |
| 结构目标 | 24 × 24 mm 外轮廓；完整底座高度、PCB 板框和装配空间待核 |
| 第二版本 | StickS3 使用另一块主机适配 PCB 和外壳，另做接口与供电验证 |

本轮将 GNSS 从此前的底部 G23/G33 提案改为主机 Grove G26/G32，以节省载板连接器占位。
G23/G33 留作备用；两路设备 TX 始终不并联。其他市售 GNSS 通过专用线束适配，必须逐款核对
电源、电平与针序。Grove、PH、SH 等插头名称不能证明互插兼容。

GNSS 以主机现有 Grove 的连接说明表达，测试焊盘放在所属网络旁。
图上保留简短标题、电压/方向和必要装配说明，详细调研与测试流程放在文档中。
此前五页把设计说明和测试计划当作独立电路页，超出了这块适配板的实际规模。

这是一页整板图的设计决定，**原生 EDA 目前仍是 A1 的五页草稿**。
本轮先完成目标与选型记录，没有删除或搬移原生电路；其中 G23/G33 的旧备注不再是首版目标。
后续依据本文件和新鲜原生回读生成单页，旧 A1 文件作为历史快照保存。
当前四器件 TXU0202 子电路只是条件式候选，不能据此决定整板拓扑。

## 器件选择

“首选”表示本阶段有依据的型号选择，仍需符号/焊盘和整板连接核对；
“条件式”需满足使用条件；“待定”必须补证据。完整清单见 [Rev A BOM](../hardware/rev-a-bom.csv)。

| 功能 | 型号 / 立创编号 | 决定与理由 |
| --- | --- | --- |
| 底座 Type-C 电源口 | HRO TYPE-C-31-M-12 / C165948 | 首选；16P 卧式，厂家图纸标称 5 A、20 V；本项目只使用 5 V 受电，D±/SBU 不承担功能 |
| CC1、CC2 下拉 | UNI-ROYAL 0603WAF5101T5E / C23186，2 颗 | 受控原型首选；每个 CC 各接 5.1 kΩ、1% 到地；两个 CC 不短接 |
| 主机支路防倒灌 | TI LM66100DCKR / C2869734 | 首选；SC-70-6、1.5–5.5 V、连续最大 1.5 A；用于主机及其 GPS 支路，必须核算温升与实际负载 |
| 高频去耦 | Yageo CC0603KRX7R9BB104 / C14663 | 100 nF / 0603，沿用 A1 已核器件；用量随最终电路确定 |
| 低频去耦 | Samsung CL21A106KAYNNNE / C15850 | 首选料号；10 µF、25 V、X5R、0805；有效容量需计入直流偏压，用量与摆放随电源设计确定 |
| 输入熔断保险 | Littelfuse 0466003.NRHF / C14165 | 条件式；3 A、32 V、1206；额定值需按整板持续电流、脉冲和温度降额，暂不冻结 |
| ATOM 配对排针 | 主机底部配对连接器 | 待实测排布、插入长度和堆叠高度后锁 MPN/封装；不把 Tiny 的 6P 套给主机 |
| Tiny 配对排母 | 1 × 6、2.54 mm 方向 | 待实测配合高度、孔坐标和额定载流后锁 MPN；不把图片顺序当 PCB 针号 |
| UART 电平转换 | TI TXU0202DCUR / C5186957 | 条件式；仅 Tiny 暴露的电平与 ATOM 不兼容时采用，还需合法的低压侧电源与掉电时序 |
| UART OE 下拉 | UNI-ROYAL 0603WAF1003T5E / C25803 | 随 TXU0202 使用，100 kΩ / 0603；已有 A1 证据 |
| GNSS 板载插座 | 首版复用 ATOM 自带 Grove | 载板无需另购此插座；线束与 GPS 电平仍须确认 |
| 测试点 | PCB 裸露焊盘 | 按最终网络放置，供电/GND/UART/必要控制信号在装配后可触达 |

Tiny 自带稳压与 UART 转换是否存在，直接决定载板是否需要对应芯片。
TPS2121 双输入选择器暂不纳入首版 BOM；这里的运行输入是底座 Type-C，主机调试 USB 通过支路隔离处理。
TUSB320 保留为后续自动识别 Type-C 电流广告的方案；若产品要求插任意 USB-C 电源自动安全运行，
必须补电流能力检测及相应的负载控制，再评估最终器件。

## 电源设计边界

计划的供电关系：底座 5 V 输入经输入保护后，一路给 Tiny 的**已核实电源入口**，
另一路经 LM66100 给 ATOM 及其 Grove GPS。Tiny 不从 ATOM 内部的 USB 二极管和 1 A PTC 取发射电流。
Tiny 支路是否需要降压器尚不能决定，不能把 5 V 直接画到未经核实的 VIN/BAT。

- 受控原型使用已核实能提供 5 V / 3 A 的电源与线材，并进行限流上电；这只是电源选择目标。
  两颗 5.1 kΩ Rd 只能声明受电端，不能证明源端会提供 3 A，也不能证明总电流已满足。
- LM66100 按 TI §8.3.2 采用 VIN 接载板电源、VOUT 接主机支路、CE 接 VOUT 的反向阻断关系。
  它不承担蜂窝大电流支路，也不提供可编程限流或过压钳位；主机 USB 同插、拔电瞬间和信号倒灌须验证。
- LM66100 在 5 V、25°C 下 RON 典型 79 mΩ；这不是全温上限。手册 5 V 条件下全温最大为 120 mΩ。
  以 0.5 A 为例，120 mΩ 对应约 60 mV 压降和 30 mW 损耗；0.5 A 是计算示例，尚非实测负载。
- 3 A 保险丝需要额外 25% 连续运行降额，基准仅 2.25 A；高温还需按曲线进一步降额。
  它不等于 3 A 电子限流器，限流电源也未必能产生足够的熔断电流。
- USB 插入浪涌、Tiny 已有电容、LTE 突发储能、ESD/过压保护和保险配合仍需共同设计。
  裸 ML307R 的推荐储能值不能未经分析直接并在 USB 口上。输入保护未冻结是整板未完成项。

## 最后需要补齐的输入

| 信息 | 影响的选择 | 当前处理 |
| --- | --- | --- |
| Tiny 板级 VIN/BAT 范围、峰值、板内稳压 | 电源入口、稳压器、保险与储能 | 不锁 Tiny 电源电路 |
| Tiny UART 实际电平、EN 定义、上电是否自动启动 | TXU0202、低压电源、EN 驱动 | 保留条件式选项；不默认 EN 等于裸模组 PWR_ON |
| 两端配对连接器几何与针号 | 具体排针/排母 MPN、封装、总高度 | 按实物核对后冻结，外壳此轮不改 |
| GPS Unit 当前修订 UART 电平与线束 | Grove 接线是否能直接使用 | 官方页面与所链旧图不一致，保留实物核验 |

这些缺口意味着**完整原理图与可下单 BOM 还未完成**。已经能确定产品范围、单页结构、
复用模块和上述通用料号；其余型号的决定有明确依赖，避免先放器件再补理由。
