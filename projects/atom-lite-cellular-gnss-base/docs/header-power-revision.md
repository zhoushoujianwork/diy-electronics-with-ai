# 排针供电修订：Header A4

日期：2026-09-27。用户决定适配板通过排针受电，后续另做独立电源模块。
本次修改落在一张 A4 图纸上；`A4` 同时是本次修订编号，见图签和工程记录。

## 当前分工

| 部分 | 职责与状态 |
| --- | --- |
| 主设备 | 提供现有 Type-C 入口；ATOM 向堆叠排针输出电源的带载能力待验证 |
| 适配板 | 接收 STACK_5V/GND，连接主机与 Tiny；不设 Type-C，保留条件式 UART 转换 |
| Tiny | 负责蜂窝通信；VIN/BAT/EN、UART 电平、实际峰值仍待板级资料 |
| GNSS | 通过 ATOM 自带 Grove、独立 G26/G32 UART 外接 |
| 后续电源模块 | 独立设计电源输入、保护、隔离与切换；接口额定值和多源行为未冻结 |

计划电源路径为 `主机 Type-C → ATOM → 排针 STACK_5V/GND → 适配板 → 已核实的 Tiny 入口`。
最后一段尚未接线。ATOM 已查官方图包含 `D5 → FUSE1 6V/1A → VGROVE_5V`，
底部 5 V 接点位于该路径；资料及修订限制见[PCB 调研第 4 节](pcb-design-research.md#4-电源方案与选择条件)。
因此主机有 Type-C 只能确定输入位置，4G 发射时的压降与温升仍需验证。

## 本次原生修改

- 移除旧 USB-C、两颗 CC 下拉、LM66100 及两颗电源电容，共 6 个器件；同步移除对应连线与旧供电说明。
- 添加 J1 两脚逻辑参考：1=STACK_5V、2=GND；排除于 BOM/PCB。
  这不是 ATOM 实际针号，也不是已选定的两脚采购连接器。
- 保留 U2 TXU0202、C3/C4 100 nF、R3 100 kΩ 的器件数据、14 个引脚网络和导线几何。
- 18 条普通文字记录供电、信号方向、尺寸及待核事项；保留两处功能标题。
- 外壳、朝下排针出口与底壳天线圆孔保持原基线。
