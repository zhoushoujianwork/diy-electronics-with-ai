# 教学路线：需求 → 调研 → 实现 → 量产

课程随着真实工程推进更新，保留失败和改版证据。下表是计划；只有 M0 的立项文档已建立，
后续内容不能作为已完成的教材案例或量产能力证明。
按用户后续顺序，先完成 Tiny [完整卡扣外壳 Rev B](../hardware/enclosure/README.md) 的参数化建模和几何检查，
接着打印试装，再做两款适配 PCB；这是机械子任务的提前迭代，M4 整体仍未验收。

| 阶段 | 要回答的问题 | 实作与交付物 | 通过依据 |
| --- | --- | --- | --- |
| M0 需求 | 用户真正要什么，哪些值是测量、标称或假设？ | 原话、需求表、来源、尺寸记录、未决项 | 原始输入可追溯；未知量不填猜测 |
| M1 调研与测量 | Cat.1/Cat-M/NB-IoT 如何选？GPS 与 4G 各负责什么？ | 型号/修订、电平/供电表、带基准的机械尺寸、成本比较 | 两端接口规格齐全；选型与真实网络/SIM 匹配 |
| M2 最小实验 | Tiny 能稳定联网？GNSS 能输出有效位置？ | 在 `demos/` 分别建立可复现的供电/UART/联网及定位实验 | 串口、供电测量、服务端回执；不从照片认定成功 |
| M3 原理图 | 各电源域、信号方向、保护和时序是否正确？ | 原理图源文件、准确封装身份、BOM、pin→net、ERC 与审查记录 | 每根线有依据；不明针脚不置 NC；下载/测试接口可达 |
| M4 PCB 与结构 | 24 mm 轮廓真的装得下吗？如何为不同主机适配？ | ATOM 适配 PCB 源、层叠、布局/RF 约束、打印模型/工艺、装配图、DRC 与回读；StickS3 变体另行设计 | 实际几何和网络检查，保存重开回读；各变体装配、受力和温升检查 |
| M5 首板与固件 | 通电、联网、定位、上传是否形成完整链路？ | 限流上电记录、固件、构建/烧录步骤、冒烟与重连测试 | 电源波形、串口和后端回执；测栈与堆，不把编译当实测 |
| M6 工程验证 | 长时间、弱网、遮挡和反复断电会怎样？ | 可靠性矩阵、外场轨迹、热/电源/RF 测试、故障清单、改版记录 | 完成需求追踪；保留失败条件与修订，不只展示最佳一次 |
| M7 小批试产 | 别人能重复做出来并测出好坏吗？ | 制造发布包、工艺、烧录/功能治具、每板测试记录、成本与良率 | 实际试产样本、数量和统计；可重建与可追溯 |
| M8 量产准备 | 供应、质量、合规和售后是否可持续？ | 批次追溯、替代料策略、认证适用性评估、返修流程与发布说明 | 评估整机适用要求；模块证书不能自动等同整机认证 |

## 每课统一记录

1. 需求与输入：来源、型号、版本、测量方法和不确定性。
2. 为什么这么选：可行方案、实际代价、决定及再评估条件。
3. 操作：可重复命令、参数文件、工具版本和前置条件。
4. 证据：原始大日志留在仓库外，提交脱敏摘要、失败点和复测结果。
5. 教学练习：例如区分波特率与定位率、计算排针跨度、用电源波形区分复位与网络掉线。
6. 本阶段结束：完成项、未覆盖项、下一步和回退版本。

## 制造包应包含

- 原理图/PCB 可编辑源与发布修订；Gerber、钻孔和板厂工艺说明。
- 精确 MPN、封装、数量、可采购替代料及其验证状态；报价日期与目标批量。
- 坐标文件、装配方向图、插件/手焊工序、外壳与紧固件图纸。
- 固件二进制与校验值、源码提交、工具链版本、烧录与出厂测试程序。
- 每设备唯一凭据的安全配置方式；公开发布包不含可用密钥或个人设备身份。
- 供电/UART/网络/GNSS/LED/按键测试项，室内 GNSS 测试受限时的室外或受控测试方法。
- 批量、合格数、失败类别、返修数和测试时间的实测统计；不能用几块样板推定量产良率。

制造包准备与工厂下单分开记录。成本上限、试产数量和收货安排未确定前没有采购订单。

## 改版与回退

用硬件修订（例如 Rev A/B）关联 EDA 源、BOM、固件和验证报告。未通过的版次保留原因；
进入下一版前提交已经完成的工作。课程叙述保留需求变化和失效分析，避免把最终答案写成一次成功。
