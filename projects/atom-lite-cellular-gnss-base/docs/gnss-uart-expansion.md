# 独立 GNSS 接入与双 UART 方案

日期：2026-09-27。设计建议，尚未生成电路或完成双串口实机验证。

## 结论

首版保留 **Tiny 4G + 市售独立 GNSS 接收板**。两款主机适配 PCB 分别提供 modem UART 和 GNSS UART，
共用经过核实的 GNSS 接口契约与线束映射。先用现成接收板验证，不急于制作裸 GNSS 模组的射频底板。

## 同为串口，为什么不能直接共用 RX/TX

TTL UART 通常是点对点接口，不带 I²C 那样的设备地址和总线仲裁。

- 4G TX 和 GNSS TX 都是输出。直接接到同一个主机 RX，会让两个输出互相驱动；即使波特率相同，
  AT 应答、4G 异步通知与连续 NMEA 数据仍可能同时出现，产生电气争用和数据损坏。
- 主机 TX 同时连接两个模块 RX，在电平/负载允许时只是广播同一串字节，不能独立配置两台设备。
  一台的 AT 命令不应交给另一台解析，因此不作为本项目接法。
- 软件“先读 4G，再读 GNSS”不能隔离实际电线，也不能停止模块的异步输出。

推荐功能连接如下；这里的 UART A/B 是逻辑通道，不是已冻结的 GPIO 或连接器针号：

| 主控端 | 外设端 | 用途 |
| --- | --- | --- |
| UART A TX | Tiny RX | 4G AT 命令与数据 |
| UART A RX | Tiny TX | 应答与异步通知 |
| UART B RX | GNSS TX | 连续接收 NMEA |
| UART B TX | GNSS RX | 配置星座、输出语句与频率，可选但建议保留 |
| GND | 两个模块 GND | 共地；电源轨分别按规格处理 |

若 GNSS 只输出位置且配置固定，可仅接其 TX 到主机 RX，连同供电/GND 共三根线。
预留四线接口更方便以后配置；PPS、复位、使能等按需要另留焊盘，不占用 modem UART。

硬件模拟开关可以将一个 UART 分时连接两个设备，但切走时会漏接 GNSS 或 4G 通知，
需要缓冲、流控和切换协议，首版不采用。若将来串口资源不足，再评估 I²C/SPI 转双 UART 芯片。

## ATOM Lite 与 StickS3 的资源安排

Espressif 官方文档分别确认 ESP32 和 ESP32-S3 具有 3 个 UART 控制器，可独立设置波特率并通过 GPIO
路由信号。UART 控制器编号不等于外壳上某个固定插座。

| 主机 | 初步资源分配 | 必须核对 |
| --- | --- | --- |
| ATOM Lite / ESP32 | UART0 保留下载/日志；另两路用于 Tiny 和 GNSS | 显式路由到可用外露 GPIO；不能照用可能连接 Flash 的默认 UART1 引脚 |
| StickS3 / ESP32-S3 | 为 Tiny、GNSS 分别分配 UART；调试接口单独保留 | Hat2/Grove 实际针位、启动脚、日志占用、板载功能与供电切换 |

对于第一轮模块实验，可优先评估 GNSS 从主机 Grove 接入，Tiny 从主机扩展口接入。
“芯片有 3 路 UART”只证明资源数量足够，最终 GPIO、电平转换和接线表仍需完成板级审核。
4G 与 GNSS 不要求使用相同波特率；GNSS 定位更新率也不等于串口波特率。

## GNSS 要做多大范围

### 首版：统一电气接口，适配现成接收板

GNSS 端预留供电、GND、主机 RX、主机 TX 四个功能。设计时明确标注信号方向，例如
`HOST_RX / GNSS_TX`，避免两端都只写 RX 而接反。

“通用”是我们定义接口后为各模块做映射，不代表市场已有统一插头标准。Grove、SH1.0、PH2.0、
杜邦排针的间距、针序与电源范围各不相同；即使插头能插进去，也要逐根核对。

- 确定连接器料号、锁扣、额定电流与 Pin 1；针序冻结后再画 PCB。
- 明确端口的供电电压与方向。M5 GPS 成品的 5 V 输入不能套用到裸 GNSS 模组。
- GNSS UART 和主控均按各自真实电平审查；“5 V 供电”不能推出“5 V UART”。
- 一次连接一个 GNSS 接收器；若在板上提供两种插座，应注明互斥使用或加切换，不能并接两路 TX。
- 每种接收板维护线束映射、波特率、NMEA/厂商协议和配置命令；NMEA 解析可复用，配置命令不保证通用。
- 给天线留下独立摆放空间；LTE 发射与 GNSS 同时工作时测试定位质量和供电噪声。

### 后续：需要缩小体积时再做 GNSS 小板

可将经过选型的裸接收模组、稳压、天线接口和必要保护做成子板，但要新增 RF 布局、天线偏置、
备份电源和生产测试工作。市售接收板通过测试不等于这块自研 GNSS 板已经通过。
