# SquareLine 静态合成界面（已归档，不推荐）

归档日期：2026-09-23。

这个目录保存一次 SquareLine Studio 静态合成实验，内容包括工程文件、导出的 LVGL
代码、Host 渲染器、图片素材和当时用于立创实战派的板级界面实现。它仅用于保留实验
过程，不参与当前固件构建，也不是本项目推荐的 UI 开发方式。

## 为什么不推荐

- 发动机主体在导出后仍然是光栅图片。单独旋转转子图层只能形成局部转动，不能表达
  不同缸数、曲轴角、活塞行程、连杆运动和逐缸点火。
- 当前 SquareLine 工作流需要在桌面 App、工程文件、生成代码和固件胶水之间人工往返，
  没有足够顺滑、稳定的 AI 图形化编辑闭环。
- SVG 或高分辨率素材最终仍需针对 320×240、RGB565 和 MCU 内存重新光栅化；直接搬入
  不能保证真机画质、动画连续性或资源开销。
- 生成界面与固件状态机之间仍要手写事件和动画绑定，修改发动机类型时复用性较差。

## 当前替代方案

当前立创实战派固件复用 M5 StickS3 的程序化发动机渲染器
`core/engine_canvas.c`。它从 18 个发动机 profile 的缸数、布局、曲轴相位和点火顺序实时
计算画面，可显示单缸、并列多缸、直列发动机、V 型发动机和水平对置六缸。

该替代方案已在立创实战派 ESP32-S3 N16R8 上以固件 0.4.1 静音烧录验证；正式 README、
UI 说明和验证记录将在真机视觉效果经用户确认后更新。

上游视觉参考及许可说明见
[`../../docs/third-party/engine-sim.md`](../../docs/third-party/engine-sim.md)。
