## 结论与适用范围

活动全名为 **「造点“硬”的 · 创出“七”迹」——嘉立创20周年系列丨立创开源七周年**。
官网鼓励将符合活动主题的原创私有项目开源，因此声浪
项目值得按该方向准备，但目前不能认定已有 EDA 工程自动具有参赛资格。

关键要求是 **嘉立创 EDA 专业版、专属活动页创建工程、板上七周年 Logo、原创且有
电路特性**。原理图和 PCB 设计完成后才满足官网所述的优惠券申请前提；只有固件、
演示视频或现成开发板运行效果，尚不足以证明满足这一前提。要参与评奖，还需要在
活动期间内完成开源发布。

## 参与步骤

以下按官网流程「报名活动 → 设计制作 → 审核发券 → 评奖发奖」整理；尚未登录走通
全部表单，具体字段和按钮顺序以官方流程文档及实际页面为准。

1. 从[活动主页](https://oshwhub.com/activities/seventh)进入「立即报名」，阅读详细
   流程和公开范围。在 **11 月 24 日前**完成报名，并保存成功提示或报名状态作为凭据。
2. 核对[报名领券表](https://docs.qq.com/sheet/DTEZKY3hua1FCbEJL?no_promotion=1&tab=BB08J2)
   的要求。官网同时提供报名按钮和报名领券表，不能假定只填其中一项就完成所有手续。
3. 在**专属活动页创建工程**，选择开源协议。创建前准备好可公开的名称、说明和材料，
   因为官网明确工程默认开源展示。已有工程如何复用、导入或关联，需要先查详细流程；
   不把普通账户中新建或已有的工程视为已关联活动。
4. 使用 EDA 专业版完成原创原理图和 PCB，在板上加入官方七周年 Logo。核对电路、
   元器件、接口和制造文件，准备可复现的开源说明。
5. 按表格/流程文档申请元器件、彩色丝印及 3D 打印支持，等待官方审核发券。券的
   实际金额、使用范围、叠加方式和有效期以审核结果及券说明为准。
6. 制作、调试并补齐实物证据，完成开源作品页。要参加评奖，须在活动期间内完成
   开源发布；活动结束日期为 **11 月 25 日**，发布是否还需审核完成应提前核实。
7. 回到活动页确认作品已关联、发布状态和结项状态，保留公开作品 URL；按官方流程
   领取结项奖励并等待评选。单独发 GitHub 或 B 站视频不能作为活动投稿成功凭据。

## 声浪项目的准备清单

2026-09-24 方向更新：确定自行设计共用声浪核心 PCB，提供 AUX 与蓝牙音频输出。
车载版首个适配目标为小鹏 X9，优先蓝牙播放并验证 OBD 踏板联动；玩具版接电子
手把、音响和电池模块。详见[共用核心板方案](shared-core-hardware-plan.md)。自研板
仍为规划，X9 数据读取与蓝牙兼容性未验证，不能作为报名资格已经满足的证据。

2026-09-25 补充：首测车型明确为 **2026 款小鹏 X9**；同时纳入特斯拉、Wi‑Fi/BLE/
经典蓝牙车辆数据适配方案。见[车辆无线接入调研](vehicle-input-wireless-research.md)。
参赛介绍只能描述适配目标和已取得的证据，尚不能宣称“全车型无线 OBD 即插即用”。

2026-09-25 开源范围确定：拟参赛部分为**共用声浪核心板与可独立运行的控制演示**；
车型解码、标定及兼容实现保留私有，不作为开源复现的依赖。既有公开来源调研保留。
活动工程默认公开，不能直接导入包含私有适配的整套商业工程；应准备只含公开部分的
原理图、PCB、固件及附件。此范围是否符合具体投稿要求仍待官方流程核验，不能将
“已设置 Git 忽略”理解为平台会替我们隐藏附件。见[开源与私有边界](open-source-boundary.md)。

建议定位：**「能看见点火节奏的摩托车声浪交互终端」**，展示实时合成与电路、屏幕、
触控和扬声器的配合。七周年主题可以用原创启动画面或声光互动表达；这是项目建议，
