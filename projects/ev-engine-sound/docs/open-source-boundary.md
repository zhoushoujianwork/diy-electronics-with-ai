# 开源核心与私有车型适配

更新：2026-09-25。项目采用共用声浪核心开放、车型适配实现保留私有的边界，支持后续
商业产品开发。本次只落实目录与协作规则；没有新增车型驱动、私有构建或远程私有仓库。

## 公开与私有范围

| 内容 | 保存与发布范围 |
| --- | --- |
| 程序化声浪核心、UI、通用控制接口、现有板级支持、测试和复现说明 | 保留在公开项目目录，遵循现有许可 |
| 规划中的共用核心 PCB、通用 AUX/蓝牙输出、独立电子手把演示 | 按开源方向开发；完成后提供可独立复现的硬件与固件，当前不宣称已实现 |
| 公开来源的 X9、特斯拉、OBD/CAN 与无线网关调研 | 保留现有调研文档；来源资料与车型实测支持分开陈述 |
| 自研的车型解码、PID/CAN 映射、年款差异、标定、休眠/唤醒兼容处理 | `private/` 或仓库外的独立私有仓库，不纳入开源交付 |
| 车型专用网关/接口板设计、商业配置、包含私有适配的固件 | 与私有实现一起管理，不混入公开 PCB 工程和发布附件 |
| 原始车辆抓包、车辆标识、私有测试记录、账号与密钥 | 留在私有存储；不得提交到公开仓库，公开记录只含脱敏结论 |

当前受 Git 跟踪的车型工作是调研与架构说明，尚无 X9 或特斯拉适配实现。既有硬件验证
范围不变，详见[验证记录](validation.md)。

## 连接方式

共用声浪核心已通过 `ev_control_t.throttle` 接受 `0..1` 油门输入。后续车型适配在私有侧
完成解码、归一化与车型标定，再把通用输入交给核心；公开演示可由按键、触摸、串口或
后续电子手把提供同类输入。通用输入的新鲜度、失效回零和渐弱规则可以公开，具体车型
报文和兼容参数留在私有侧。当前未新增网关传输协议或驱动加载接口。

默认公开构建不能依赖 `private/` 存在。私有集成后续采用显式启用的构建入口和单独的
产物目录；含私有代码的二进制、符号文件、日志与打包材料均按私有内容管理。开放接口
本身不会消除所使用第三方代码的许可义务。

## 本地目录和 Git 行为

项目内的 `.gitignore` 明确忽略 `/private/`，仓库根目录也已有 `private/` 规则。以下为
约定路径，可按需创建；其中内容不由公开仓库提供：

```text
projects/ev-engine-sound/
├── core/                       # 开源声音与通用控制
├── firmware/                   # 开源板级固件
├── docs/                       # 可公开的方案和脱敏证据
└── private/                    # 忽略目录；本地私有工作区
    ├── adapters/               # 车型解码及兼容实现
    ├── hardware/               # 车型专用网关/接口板
    ├── calibration/            # 车型参数
    ├── evidence/               # 原始抓包与私有验收记录
    └── dist/                   # 私有构建与商业交付产物
```

`.gitignore` 只阻止未跟踪文件被常规 `git add` 纳入，不提供加密、访问控制或备份。
`git add -f` 仍可绕过规则；压缩整个工作目录、上传 EDA 工程或发布视频也不会自动遵守
Git 忽略规则。公开附件应从干净的公开检出目录制作，并检查生成产物和附带材料。

从仓库根目录可以检查：

```sh
git check-ignore -v projects/ev-engine-sound/private/adapters/example.c
git ls-files -- projects/ev-engine-sound/private/
```

前者应命中本项目忽略规则，后者应无输出。已跟踪的文件不会因为新加忽略规则而消失；
`git rm --cached` 也只影响之后的版本，不能清除历史。此变更不删除已有调研、不重写
历史，也不改变以前已经授出的许可证。

开始积累实际适配代码时，建议放入**公开仓库之外的独立私有 Git 仓库**，使用单独的
远程访问权限、版本和备份。本地 `private/` 可作临时工作区，但当前没有私有远程或自动
备份，不能依赖公开仓库恢复其内容。

## 许可与活动交付

商业使用与开源并不冲突。[现有 MIT 许可](../../../LICENSE)允许他人使用、修改和销售
公开部分，须保留版权与许可声明。因此保留自研适配的私有实现，可以保留这部分的
交付价值，但不能据此禁止他人商业使用已公开的 MIT 核心或自行实现车型适配。

自研私有内容应单独声明权利及交付条款；第三方代码、DBC、库和 SDK 仍按其原许可证
处理。尤其不能把 GPL 代码复制到 `private/` 就视为可免除分发义务。此前车辆调研未
引入 GPL 实现；今后复用或随产品分发前需核对实际依赖与义务。

立创开源七周年拟交付**可以独立复现的声浪核心板与独立控制演示**，车型私有适配不作为
公开作品的必需依赖，也不把其功能列为开源复现承诺。自研 PCB 与电子手把仍需完成和
验证。活动工程默认公开，创建或导入前应使用仅含公开部分的工程；是否接受这一具体
参赛范围仍需按官方流程核验，见[活动参与记录](oshwhub-seventh-participation.md)。
