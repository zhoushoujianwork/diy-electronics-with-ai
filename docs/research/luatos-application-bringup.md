# LuatOS 自定义应用的开发与验证要点

本页区分官方API事实和去标识化工程经验。工程经验是可复用方法，不是任何具体板修订、私有部署或整机的验收证明。资料核对：2026-10-14。

## 先确认目标，再选择应用包

**工程经验：**同一产品家族或Lua版本可能对应不同core、分区和bytecode ABI。安装包文件名、bitw参数、模块型号和主板型号是不同证据。烧录前记录实物修订、已安装core、原应用版本、bytecode头、匹配编译器和实际分区；不能仅以“都是Lua5.3”判断兼容。

源码目录审查、离线编译、下载成功、重启运行和恢复成功分别验收。只读取脚本区不等于完整Flash/NVM/校准数据备份；软件进入下载枚举也不等于能够写入。只更新应用时优先明确限制写入范围，并保留恢复依据，避免默认全量擦写。

## FSKV按物理块预算

**官方事实：**[FSKV文档](https://docs.openluat.com/osapi/core/fskv/)说明总空间64KiB、16个4KiB块，初始两个块用于小值；value≤255字节的小值共用初始空间，value≥256字节的每对KV占一个块，大值理论最多14对。总字节数除以JSON长度不能作为大值队列容量。

**工程经验：**业务上限应低于物理极限，为元数据和回收留余量。长时断网需要按采样周期、值大小和擦写寿命选择存储方案；小型KV不应自动承诺全天轨迹。更新已确认水位后回读，再回收对应槽；队满要退避、计数并保留未确认数据。清空整个KV区可能破坏身份、序号、业务缓存或原厂键，不应作为常规修复。

## 数值边界是通信协议的一部分

**官方入口：**[JSON](https://docs.openluat.com/osapi/core/json/)、[MCU计数器](https://docs.openluat.com/osapi/core/mcu/)、[SNTP与socket](https://docs.openluat.com/osapi/core/socket/)。

**工程经验：**宿主解释器的int64/double不能自动代表目标。对UTC毫秒、递增序号、到期时间、计数器回绕和明确0/false做边界验证；目标格式器也可能改变JSON数值表示。需要时以整数秒和毫秒余数运算并直接生成整数JSON，拒绝已失真的浮点元数据。采用哪种表示都要用实际编译器、目标格式器和服务端解析器核对。

## 选卡、板级电源和require副作用

**官方入口：**[mobile.simid](https://docs.openluat.com/osapi/core/mobile/#mobilesimidid-priority)、[PM](https://docs.openluat.com/osapi/core/pm/)、[GPIO](https://docs.openluat.com/osapi/core/gpio/)。

**工程经验：**默认SIM、板上卡座命名和API编号要分别确认。API第一次返回不等于最终就绪，继续检查SIM状态、网络地址和可信时间。自动选卡可能复用板上其他信号，不能在未核对引脚时试遍模式。

外设库可能在require阶段注册GPIO/电源回调；加载库之前审查顶层行为、型号分支、供电和中断占用。只读观察充电IC既有值，不等于电芯规格认证或已经停止充电。USB输入在位、实际充电、电芯电压和系统电源轨是不同状态；未知字段应保持未知。

## 让可观测性独立推进

**工程经验：**运动中断只更新内存，避免在回调里进行Flash、文件系统或联网。心跳、LED和调试输出应有不依赖MQTT/存储完成的调度路径；同时承认共享Lua VM的定时器可能被同步原生命令延迟。状态转换日志和递增回调数证明代码推进，看到实物发光才证明可见输出。

灯光定义属于应用协议，不能跨固件套用。GNSS解析器fix、新鲜/质量通过的位置以及后台已存坐标也要分别判断。G-Sensor、三轴运动检测与六轴IMU不能互换名称。

## 分层定位联网故障

**官方入口：**[MQTT API](https://docs.openluat.com/osapi/core/mqtt/)。

**工程经验：**依次核对SIM/IP/UTC、DNS、监听/证书、主机规则、上游入站规则、TLS/认证/Topic权限、consumer和数据库。服务本机TLS成功不代表蜂窝路径可达；TCP连通或QoS1 PUBACK也不证明消费端事务完成。结合客户端日志、抓包和只读规则查询定位，再做最小变更并保存撤销依据。

## 保存验证边界

**工程经验：**记录精确板修订、固件源码、core、供电和持续时间；扫描错误首行、复位原因、USB重枚举、脚本异常和心跳间隔。每次升级重新计算窗口，不把旧版时长加给新版。编译、下载、串口、数据库和物理观察分别给结论；位置、充电、断电、低功耗和续航需要对应的实物测试。

原始串口、设备身份、凭据、坐标、厂商镜像和完整备份保存在Git外。知识页只保留上述通用方法和公开来源，不附私有项目、服务器或用户标识。
