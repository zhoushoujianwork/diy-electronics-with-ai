# 版式与提示词

## 详细三页手册

使用统一白底、深灰正文、一个产品主色和少量状态色。每页都有页码、适用型号/固件与“示意图”标记。
默认横版 16:9；图片分辨率以工具实际产物为准。长篇正文留在配套 Markdown，保持目标阅读尺寸下可读。

| 页 | 图文组织 | 易错处 |
| --- | --- | --- |
| 认识硬件 | 左侧产品与部件；右侧接口/接线表；底部电源注意事项与未使用能力 | 接口镜像、主机/外设 TX/RX 混淆、板载能力被当作项目功能。 |
| 按键与状态 | 状态页和操作页分开；旁边逐行解释；底部按键卡和状态对照 | 虚构菜单、把模块在线当定位成功、把代码示意当实机截图。 |
| 上手与排查 | 顶部实际数据路径；中部编号步骤/条件分支；底部症状与下一步 | 缺少配置或服务前提、扫码功能臆造、宣称未完成验收。 |

可删减或扩展页数。硬件未使用的能力只占一个简短区块，不抢占主任务空间。
关系图中所有线有明确语义：供电、UART、Wi-Fi、互联网、反馈；不混用一个箭头表示不同关系。

用户要求技术原理或完整 Demo 时，可追加“原理篇”：从传感器数据和有效性判断开始，连接设备处理、上传协议、平台保存、账号/设备关系及最终查看/分享。将“用户注册”“设备接入开通”“绑定所有权”“授权他人查看”分开说明；邀请链接的有效期不等于已经授予的查看权限到期。不要把其他板型的蜂窝、SD、惯导等能力套用到本设备。
独立补充篇可使用“原理篇”标题，保留前面操作手册的页码体系。并列的屏幕状态来自不同时刻时必须标明，避免形成矛盾的实时状态示意。

## 内置生图提示词骨架

```text
Use case: infographic-diagram
Asset type: 产品使用说明书第 N/M 页
Product: 型号、硬件修订版、固件依据
Input roles: Image 1 产品身份；Image 2 配件身份；Image 3 仅版式参考
Identity invariants: 轮廓、前后方向、按键/端口数量和位置、配色、附件
Layout: 本页区块位置与信息层级；与上一页统一字号/配色/页码
Text (verbatim): 按区块列出完整精确文案，包括单位、标点、英文状态名
Diagrams: 各对象和箭头端点、含义；表格的列头及逐行内容
Evidence label: 固件实现 / 已测范围 / 待验收，按本页实际情况填写
Privacy: 所有示例数据均为公开占位；无真实凭据、验证码、IP、位置
Avoid: 未列出的功能、隐藏端口、额外按键、参考图产品、虚构菜单、二维码和参数
Render one standalone page. Preserve product identity and exact text.
```

占位符在调用前全部替换；不需要的输入或模块直接删除。
修图时引用实际失败图，逐条说明修改，保留已经正确的产品、文案与区块。输入图太多时优先保留身份与编辑目标，减少无关布局参考。

## 事实卡建议

`facts.md` 使用表格：事实 ID、结论、硬件/固件/验证层级、来源路径或官方链接、版本、限制。
`generation.md` 记录每页完整提示词、输入图角色、生成方式、输出文件/真实尺寸与 `PASS / FAIL / NOT CHECKED` 检查表。
校对需要面对实际图片，文件存在、提示词正确或 OCR 通过本身都不表示图片正确。
