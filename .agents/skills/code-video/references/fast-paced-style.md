# 快节奏动感风格（实战沉淀）

来源：为一个开源 CLI 项目做的 41 秒推广片 v2。v1 是 61 秒、每屏大段文字、静态卡片，用户反馈
「没有动感快节奏、文字太多、动画太少、想要宠物」。以下做法是针对这条反馈验证过的。
模板代码在 [templates/](../templates/)，复制到目标项目后改，不要在 skill 目录里直接渲染。

## 节奏：一切对拍

- 固定 120 BPM，`BEAT = 0.5`。场景 `dur` = 整拍数 + `FADE`（0.25），这样每个场景的起点都落在拍子上。
  起点序列由 `timeline.js` 累加得出，不手写。
- 配乐每拍一声底鼓，`energy ≥ 0.6` 时反拍加 hi-hat。画面背景光晕用同一个 `BEAT` 做 `kickPulse`
  脉动（`bgBeat`），所以画面和声音天然同步，不需要对时间轴。
- 单场景 4 到 8 秒。8 秒以上就该拆。7 个场景合计 41 秒，信息量比 61 秒的 v1 大。
- 交叉淡入 0.25s（v1 的 0.5s 在快节奏下显得拖）。

## 文字：每屏一两个词

- 标题用 `popWords`：逐词弹出，带回弹过冲（`pop`），每个词配一声 `pop` cue。
- 场景标签用 `kicker`（左上角单词弹出），如「布局」「布线」。
- 能用图形表达就不写字：能力清单用图标卡网格，流程用数字卡，结果用滚动数字。
- 只有命令、网址、数据来源标注允许成句，且字号不小于 27px 并保证不溢出。

## 动画元素库（`fx.js`、`pet.js`）

| 元素 | 用途 |
| --- | --- |
| `burst` | 方块碎屑爆开，落点强调 |
| `ring` | 扩散光环，配 `hit` |
| `traceRays` | 8 方向成对走线 + 端点焊盘，开场和收尾 |
| `confetti` | 全屏方块彩屑，收尾庆祝 |
| `polyPath` / `polyAt` | 折线按进度描绘，以及取线上某点（让宠物沿线跑） |
| `chip` | 芯片图标（方体 + 四边引脚） |
| `pop` | 0→1 带回弹的缩放包络，几乎所有出场都用它 |
| `drawPet` 等 | 像素小宠物，见下 |

## 像素宠物

- 原创像素角色：橙色方块身体（12×6 单位）、竖条眼睛、两只小手、四条短腿。配色借用 Claude 的橙色调，
  不是官方素材，对外要如实说明。
- 原点在脚底中心，1 单位 = `u` 像素，`u=14` 约 170px 宽，放在 `GROUND` 线上。
- 状态全由参数给出，保持纯函数：`walk` 走路相位（`null` 站立）、`squash` 压扁拉长、`lean` 前倾、
  `armL/armR` 举手、`eyes` 为 `open | blink | happy`。`autoEyes(t)` 每 3.1 秒眨眼。
- `hopAt(t, period, h, phase)` 返回 `{dy, squash}`，用 `period = BEAT` 就是随拍子跳。
  `petShadow` 跟随离地高度缩放阴影。
- 叙事分工：开场走入并跳、搭建时扔器件、布线时跑、结果页举手欢呼、收尾旁观。
  宠物让每个场景都有「角色在做事」的动态，是降低文字量的主要手段。
- 放置要避开主体：宠物不能压住标题、数字卡和对勾，并留出地面阴影的高度。

## 音频声部（`tools/lib/synth.mjs`）

声部：`whoosh hit click tick pop ok chime kick hat clap riser boing thud`。`hit chime kick thud clap riser`
居中，其余按 seed 确定性左右分布。增益在 `BASE` 表里统一调，底鼓 0.6。全部振荡器加滤波噪声合成，
无采样。实测成片 -19.1 LUFS、LRA 2.0 LU、真峰值 -4.4 dBFS，满足 < -1 dBFS。

## 流程教训

1. **先做场景表再写码**：列出每场景的拍数、主动画、cue 时刻、最终态，再动手。
2. **边做边看**：每个场景写完先 `stills.mjs` 出 6 帧看，再写下一个。本次前两轮几乎每个场景都被抓到版式问题：
   命令字号过大溢出、宠物压住标题、卡片文字贴边、数字卡宽度不足、宠物头顶贴数字卡。
3. **结尾帧要单独看**：淡入期间的联络图看不出最终态是否停稳，要抽 `dur-0.05` 的真实结尾帧。
4. **真实数据要标出处**：结果页的数字取自仓库已有的案例文档，画面里标「历史案例 · 文档路径」，
   不冒充本轮现场验证。
5. **旧版本先备份**：改版前把旧成片和旧场景目录改名保留（`promo-v1.mp4`、`scenes-v1/`），便于对比和回退。
6. **渲染顺序**：先 `score.mjs`（音频同源，也能快速暴露 cue 类型拼错），再 `render.mjs`，最后 `mux.mjs`。
   `mux.mjs` 内置音画时长差 ≤ 0.25s 的断言。
7. **听不了就明说**：数值正常不等于好听，交付时请用户自己听节奏、音色和混音。

## 环境陷阱

- macOS 自带 BSD `sed`，`sed -i` 带换行会失败；改源码用编辑工具或脚本。
- Chrome 路径写在 `tools/lib/browser.mjs`，用环境变量 `CHROME_PATH` 覆盖；中文字体 PingFang SC 只在 macOS 上有。
- `drawLogo` 的裁剪区 `crop=[sx,sy,sw,sh]` 要按目标 logo 图实测，不给则整图缩放。
