# 合宙流量卡 OpenAPI

先读 [API 契约与歧义](references/api.md)，按用户所需操作选择接口。这是资料查询与接入工作流；实际账号配置和在线验证状态须在运行时检查，技能源码不附带客户端或凭据。

## 资料与调用准备

- 资费查[合宙官方产品页的流量卡说明](https://docs.openluat.com/air8781p/product/)，采购前复核现行报价。用户转述的补充说明不能当作已公开核实的事实；本技能不依赖私有研究记录。
- 明确查询的是卡状态、指定日/月用量、账户余额还是可充值套餐；选择单卡或批量标识，遵守互斥字段及日期格式。查询接口也是 POST，不能按 HTTP 方法判断副作用。
- API 使用独立的 `appkey/appsecret` HTTP Basic 认证；网页登录账号和测试登录不是 API 凭据。缺少凭据时完成接口选择、脱敏 JSON 请求准备及字段说明，说明在线验证缺口。
- 密钥优先由环境变量 `OPENLUAT_SIM_APPKEY`、`OPENLUAT_SIM_APPSECRET` 成对注入；未设置时读取本机 `${XDG_CONFIG_HOME:-~/.config}/openluat-sim/credentials.json` 的 `appkey`、`appsecret`。仅配置文件存在且两字段齐全才视为已配置，不推定其他机器有凭据；目录权限 `700`、文件权限 `600`，拒绝符号链接和组/其他用户可访问的凭据文件。不要把配置复制到技能目录或 Git。
- 在请求进程内读取密钥，不放进源码、命令行参数、示例或日志；不输出配置内容、Authorization 头或带认证的请求转储。真实卡号、设备标识、账号、余额和流量结果留在私有运行环境，只提交合成或脱敏示例。

## 传输与真实查询

文档只列 HTTP 基址，Basic 认证本身不加密传输。优先核验供应商提供的 HTTPS 或其他安全传输方案；用户未明确授权明文认证时，不经 HTTP 发送真实凭据。若用户已明确授权向文档中的 API 主机使用 HTTP 认证，则在该授权的账号、目标和查询范围内执行，不把这次授权变成其他用户或其他主机的默认设置，也不重复询问已有的具体授权。不要仅替换 URL 就宣称支持 HTTPS，不跳过证书验证；本地代理不等同于端到端 TLS。禁止将 Authorization 转发到其他主机，遇到重定向先停止核对。

满足传输条件、有正确凭据且查询范围已获用户授权后，按文档契约执行相应查询，分别检查 HTTP 状态和业务 `code`。报告数据时间与单位，保留响应结构歧义；不得把离线请求准备说成查询成功。不要扩展到用户未要求的全账户卡列表。

## 短信、充值与回调

- `sms_submit` 会发送短信，`make_order` 会充值下单。建 Skill、查看套餐或查询余额均不授权这些写操作。
- 执行前准备可审查的目标卡范围、短信内容或充值套餐、数量及费用，依据用户明确的操作授权执行；现有授权已足够具体时不重复确认。缺少必要信息时先补齐，不从查询推定写入授权。
- `extra_no` 不代表已承诺幂等。充值超时后先核实平台订单/余额和实际生效情况，不能盲目重试或自动续费。
- 短信回调的认证、重试和响应契约未说明，不能仅凭收到回调确认可信业务状态。文档没有停复机接口，不声称支持。
